# Slacking Ultima
Slacking Ultima is a Slack Bot that I have created to help you in basic utilities and fun commands. It was built using Python (Bolt)'s Framework, I made it run 24/7 by using PM2 on Hack Club Nest.
While building this project i learnt a lot of stuff like how to connect python to slack, use slack bolt, create commands, write unique input/output things and much more!



Here is some of the **Commands** which you can run!

* /ultima-hello - Says Hello 
* /ultima-ping - Checks bot's status 
* /ultima-roll - Rolls a number 
* /ultima-joke - Tells you a random joke 
* /ultima-calc [Calculation Input] 
* /ultima-rps - Play Rock paper scissors with the bot! 
* /ultima-tz - Gets the timezone of some places

I plan on maybe adding more commands in the future :)
