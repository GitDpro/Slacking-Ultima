# Slacking Ultima
Slacking Ultima is your personal slack bot that runs 24/7 using PM2 on Hack Club Nest and built with python (Bolt) framework + Socket Mode, Made for your community to bring them closer together and assist them daily :)

Here's what it can do!
**Features**

* /ultima-hello - Says Hello 👋
* /ultima-ping - Checks bot's status 
* /ultima-roll - Rolls a number 
* /ultima-joke - Tells you a random joke 😂
* /ultima-calc [Calculation Input] 🔢
* /ultima-rps - Play Rock paper scissors with the bot! 🖐️ 
* /ultima-tz - Gets the timezone ⏳
